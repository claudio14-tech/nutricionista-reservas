SUBIR A GITHUB
1. Abrir https://github.com/claudio14-tech/nutricionista-reservas
2. Abrir index.html y elegir el lápiz Edit this file o cargar la nueva versión.
3. Reemplazar el contenido por este index.html (en un computador), o desde Safari en iPhone, eliminar el index.html anterior y subir este archivo con el mismo nombre.
4. Confirmar los cambios con Commit changes.
5. Si GitHub Pages está activado para main/(root), al publicarse se actualizará el mismo enlace.

NOTA WHATSAPP
